# 💳 Техническая интеграция Stripe Checkout без Webflow E-commerce

Данный документ описывает, как реализовать онлайн-оплату картами и Apple Pay со скидкой **-20%** для одной услуги и для всей корзины на стандартном тарифе **Webflow CMS**, экономя сотни долларов в год на тарифах E-commerce и комиссиях.

---

## 🎯 1. Почему этот подход лучше Webflow E-commerce

| Параметр | Webflow E-commerce Plan | Наш Stripe Checkout + Webflow CMS |
|---|---|---|
| **Стоимость тарифа** | $42 – $235 / месяц | $23 / месяц (стандартный CMS план) |
| **Комиссия платформы** | 2% сверх комиссии Stripe | **0% комиссии** (только стандартный Stripe) |
| **Динамические скидки -20%** | Сложно настроить без промокодов | **Автоматически встроены** в JS-логику |
| **Передача слотов и даты** | Требуются костыли | **Нативная передача** в Metadata Stripe |
| **Apple Pay & Google Pay** | Ограничено | **Встроено из коробки** в Stripe Checkout |

## ⚙️ 2. Как технически работает оплата

### Сценарий А: Оплата 1 услуги (со страницы услуги или из каталога)
1. Клиент выбирает длительность (например, *Authentic Thai 90 min* = 1 350 ฿) и количество гостей (2 гостя).
2. Базовая цена: `2 × 1 350 = 2 700 ฿`.
3. Онлайн-цена со скидкой 20%: `2 160 ฿`.
4. Клиент нажимает **«Оплатить онлайн со скидкой -20% (2 160 THB)»**.
5. JavaScript обращается к защищенному эндпоинту создания Stripe Checkout Session.

### Сценарий Б: Оплата всей корзины (Мульти-заказ)
1. В корзине 3 разные услуги:
   - *Authentic Thai (60 min)* — 1 шт. × 760 ฿ (было 950 ฿)
   - *Gua Sha Facial (60 min)* — 2 шт. × 840 ฿ (было 1 050 ฿)
   - *Pre-Tan Scrub (30 min)* — 1 шт. × 600 ฿ (было 750 ฿)
2. Итого к оплате онлайн: `760 + 1680 + 600 = 3 040 ฿` (вместо 3 800 ฿).
3. JavaScript формирует массив `line_items` со всеми позициями и скидками и открывает чекаут.

## 🛠️ 5. Как подключить на практике (Пошагово и простым языком)

### 💡 Почему нужен безопасный посредник (Make.com)?
У Stripe есть два ключа:
1. **Публичный ключ (`Publishable Key`)** — это открытый ключ, его можно размещать на сайте в Webflow.
2. **Секретный ключ (`Secret Key`)** — это как **PIN-код от банковского счёта салона**. Его нельзя вставлять в открытый код сайта, иначе его смогут украсть через просмотр кода страницы (F12).

Поэтому между Webflow и Stripe используется бесплатный сценарий в **Make.com**, который безопасно хранит секретный ключ.

---

### 🔄 Пошаговая настройка за 3 простых шага:

#### Шаг 1. В кабинете Stripe:
1. Зарегистрировать аккаунт салона на [stripe.com](https://stripe.com) (тайское юрлицо или международный аккаунт).
2. Зайти в раздел **Developers ➔ API keys** и скопировать два ключа:
   - `Publishable key` (начинается на `pk_live_...`)
   - `Secret key` (начинается на `sk_live_...`)

#### Шаг 2. В кабинете Make.com (Безопасный кассир):
1. Создать сценарий из 2 модулей:
   - Модуль 1: **Custom Webhook** (принимает список услуг из корзины сайта).
   - Модуль 2: **Stripe: Create a Checkout Session** (подключаем Secret Key из шага 1, выбираем валюту `THB`, передаём сумму со скидкой 20% и метаданные брони).
2. Make.com выдаст одну ссылку вебхука (например, `https://hook.make.com/abc123xyz`).

#### Шаг 3. В Webflow:
1. Вставить выданный вебхук URL в настройки страницы или глобальный скрипт перед `</body>`.
2. При клике на кнопку «🔥 Оплатить онлайн со скидкой» сайт отправляет данные в Make.com, получает ссылку Stripe Checkout и моментально перенаправляет клиента на защищенную оплату с **Apple Pay** или банковской картой.

---

### 🎁 Альтернативный ультра-простой вариант (Stripe Payment Links):
Если на первом этапе не хочется настраивать вебхуки для динамической корзины, в Stripe есть функция **Payment Links**:
1. В панели Stripe нажимаем **«Create Payment Link»** для каждой из 16 процедур со скидкой 20% (например: *Thai 60 min* = 760 ฿, *Thai 90 min* = 1 080 ฿).
2. Stripe генерирует постоянные ссылки (например: `https://buy.stripe.com/abc...`).
3. Привязываем эти ссылки прямо к кнопкам оплаты на страницах услуг в Webflow.
