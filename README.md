## 🚀 Быстрый запуск и деплой на GitHub Pages

Проект создан на чистом стеке (**Vanilla HTML5 / CSS3 / ES6+ JavaScript**) без внешних фреймворков и сборщиков. Работает «из коробки» на любом статическом хостинге.

### Инструкция для выгрузки на GitHub:
1. Создайте новый репозиторий на GitHub (например, `nua-shop` или `iamnua-store`).
2. В терминале внутри этой папки выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: IAMNUA catalog and shop"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings** ➔ **Pages**:
   - В разделе **Branch** выберите `main` и папку `/(root)`.
   - Нажмите **Save**.
4. Через 1 минуту сайт будет опубликован и доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## 💎 Ключевой функционал

1. **16 Аутентичных процедур:**
   - Полностью очищенный датасет (удалены дубли и комбо из Fresha, только чистые индивидуальные услуги салона).
2. **2 Режима отображения каталога:**
   - *Сетка карточек* (Grid Mode) с быстрым выбором длительности и пересчетом цен.
   - *3-колоночное меню* (Menu Mode) в стиле традиционной чайной / спа-карты.
3. **Отдельная внутренняя страница для каждой услуги (Product Detail Page):**
   - Breadcrumbs-навигация (`Каталог / Категория / Услуга`).
   - Галерея высокого разрешения с интерактивным переключением ракурсов.
   - **Уникальные 4 шага ритуала** для каждой процедуры.
   - **Индивидуальные показания и эффекты для тела**.
   - **Точный состав масел и косметики** (нефрит, французский лифтинг, вулканические базальтовые камни, кокосовое масло прямого отжима и т.д.).
   - Калькулятор гостей (1 гость / 2 парный / 3+ гостей) и даты.
   - Фиксированный сайдбар при скролле (**Sticky Sidebar**).
   - Кросс-категорийные рекомендации со спа-чипами длительности.
4. **Выдвижная корзина (Cart Drawer):**
   - Быстрое добавление услуг прямо из каталога или со страницы услуги.
   - Мульти-заказ и общий пересчет стоимости с выгодой **-20% при онлайн-оплате**.
5. **Платежные сценарии:**
   - Интерактивный мокап **Stripe Checkout** (Apple Pay / банковские карты с фиксацией 20% скидки).
   - Прямая бронь **без предоплаты** (оплата в салоне на месте).
